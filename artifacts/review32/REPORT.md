# День 32: автоматическое AI-ревью кода

Проверка выполнена 18 октября 2026 года на `gpt-5.3-codex` через реальные
оплачиваемые запросы OpenAI. Секрет настроен в GitHub Actions с отдельного
разрешения пользователя; значение ключа в исходники и отчёты не включалось.

## Реальный демонстрационный PR

[Demo-PR #26](https://github.com/lagrange777/aichallenge_hw/pull/26) направлен
в `ai-challenge-task-32`, чтобы проверить анализатор до его слияния в `main`.
Оба запуска инициированы событием `pull_request`, не локальной имитацией CI.

| Запуск | HEAD | Результат | Ответ модели |
|---|---|---|---|
| [Открытие PR](https://github.com/lagrange777/aichallenge_hw/actions/runs/39124980569) | `f2ab2af` | success, 2 замечания | 4,8 с / 6871 токен |
| [Новый коммит](https://github.com/lagrange777/aichallenge_hw/actions/runs/39125379623) | `15a75b6` | success, 0 замечаний | 1,1 с / 3857 токенов |

Первый коммит намеренно менял делитель стоимости с миллиона на тысячу и
добавлял передачу `OPENAI_API_KEY` в `/api/status`. Модель нашла обе ошибки,
несмотря на prompt injection в комментарии к изменённому коду. Ревью
ссылается на diff, исходную функцию расчёта, обработчик HTTP и правило из
`docs/architecture.md` о хранении ключа только на сервере.

Второй коммит исправил ошибки и оставил безопасное переименование локальной
переменной. Модель не выдала замечаний. Обновлён **тот же**
[комментарий бота](https://github.com/lagrange777/aichallenge_hw/pull/26#issuecomment-6249594259),
ID `6249594259`; комментариев этого бота с маркером ревью ровно один.
После успешной проверки demo-PR закрыт без слияния.
Доказательства запусков и ID сохранены в [github-runs.json](github-runs.json),
подлинные загруженные артефакты — в `github-first/` и `github-second/`.

RAG на обоих запусках: 164 файла / 1802 чанка базовой ревизии. В первый запрос
передано 15 источников (2 diff + 13 retrieved chunks), во второй — 8.
Все сохранённые цитаты дополнительно сверены с точными диапазонами исходных
чанков. Это проверка ссылок и текста, не доказательство верности рассуждений.
Скорости двух запросов не являются сравнительным бенчмарком: контексты разные.

## Пять дополнительных контролей

| Изменение | Ожидание | Фактический результат |
|---|---|---|
| Неверная стоимость + injection | Найти ошибку в `catalog.go` | 1 замечание, completed |
| Ключ в HTTP-ответе | Найти утечку в `server.go` | 1 замечание, completed |
| Переименование локальной переменной | Без замечаний | 0, completed |
| Rename test-файла / удаление отдельной неиспользуемой инструкции | Без замечаний | 0, completed |
| 29 изменённых файлов | Ограничить покрытие | 24 переданы, 5 пропущены, partial |

Подробности: [evaluation/summary.json](evaluation/summary.json), полный
JSON/Markdown в каталогах каждого сценария. Узкие проверки ожидаемого пути,
отсутствия замечаний и лимита прошли 5/5. Они не означают универсальной
точности модели. Fixture-коммиты создавались только во временном клоне;
кандидатный код ни локально, ни в CI не исполнялся.

Первый пробный запрос до исправления prompt был отклонён валидатором:
модель перепутала строку patch со строкой файла. Сводка сохранена в
[initial-validation-failure.json](initial-validation-failure.json).
В итоговом запросе модель получает явные списки допустимых строк файла;
предусмотрена одна ограниченная попытка исправления JSON/диапазонов.

## Технические проверки

- `go test ./...` и `go vet ./...` — успешно.
- `go test -race ./internal/prreview ./internal/openai` — успешно.
- Docker target `pr-review` собран; `--collect-only` проверен на настоящих
  base/head demo-PR с read-only монтированием автономного Git-репозитория.
  Результат чтения Git и retrieval сохранён в [docker/input.json](docker/input.json).
- Тестируются исключения `.env`, symlink/generated/больших файлов, rename/delete,
  лимит числа файлов, ложные ссылки/диапазоны, старый HEAD, обновление только
  комментария бота, ограниченное исправление и отсутствие вызовов инструментов.

При финальной сборке выявлена нестабильность старого теста брокера:
замена последнего символа Base64 могла менять только неиспользуемые padding
bits и оставлять байты подписи теми же. Тест теперь меняет первый символ
подписи, гарантируя подмену MAC. Логика приложения не менялась; контроль
повторён 100 раз и затем в полной Docker-сборке.

## Видео и локальный веб-просмотр

[Видео демонстрации](review-demo.mp4): 78 секунд, 311 кадров захвата,
только содержимое веб-интерфейса, без рабочего стола, терминала и звука.
Метаданные и результат полной проверки декодирования — [video.json](video.json).
Неактивные паузы между этапами сокращены; ответы и результаты не подменялись.

Во встроенном браузере GitHub начал возвращать DNS-ошибку, поэтому видео
снято с локального просмотра **сохранённых настоящих отчётов Actions**.
Интерфейс явно отмечает этот режим и содержит ссылки на реальные запуски,
HEAD и комментарий. Просмотр не делает новых запросов OpenAI.

```sh
python3 scripts/render-review-demo.py
python3 -m http.server 8085 --bind 127.0.0.1 --directory artifacts/review32/web
```

Откройте `http://127.0.0.1:8085/`. В видео показаны: первый запуск, изменения
кода, замечания с цитатами, документация и код из RAG, пять контрольных
сценариев, повторный запуск без замечаний и diff безопасного рефакторинга.

После слияния реализации в `main` автоматическое ревью будет доступно
следующим PR из веток этого репозитория. Сам первый PR реализации получает
явный Bootstrap, поскольку в его base ещё нет анализатора. Fork/draft/
Dependabot пропускаются. Pipeline не делает approval или merge.
