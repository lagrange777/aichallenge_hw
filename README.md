# Codex Chat CLI

Минимальное CLI-приложение на Go для диалога с Codex-моделью через OpenAI
Responses API. История продолжается через `previous_response_id` и существует
только до завершения процесса.

Интерфейс повторяет основные паттерны Codex CLI: стартовая карточка с моделью и
рабочим каталогом, компактный prompt `›`, визуально отделённые ответы, индикатор
выполнения и slash-команды.

Архитектурные решения и ссылки на официальную документацию собраны в
[`ARCHITECTURE.md`](ARCHITECTURE.md).

## Требования

- Go 1.22 или новее;
- OpenAI API key с доступом к выбранной модели;
- настроенный биллинг OpenAI API, если он требуется для аккаунта.

Подписка ChatGPT и биллинг OpenAI API — отдельные продукты.

## Запуск

Задайте ключ в окружении текущего терминала:

```sh
export OPENAI_API_KEY="your-api-key"
go run ./cmd/codex-chat
```

Ключ не нужно добавлять в исходники. Приложение читает его только из
`OPENAI_API_KEY`; для локального запуска удобнее экспортировать переменную в
текущем терминале.

По умолчанию используется `gpt-5.3-codex`. Другую доступную модель можно выбрать
без изменения кода:

```sh
export OPENAI_MODEL="gpt-5.3-codex"
```

Дополнительные настройки:

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `OPENAI_MODEL` | `gpt-5.3-codex` | ID модели |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | базовый URL API |
| `OPENAI_TIMEOUT` | `2m` | тайм-аут одного запроса |

## Запуск в Docker

В образ попадает только статически собранный бинарник и корневые сертификаты.
Компилятор, исходники и API-ключ в финальный образ не копируются.

Самый короткий вариант запуска:

```sh
export OPENAI_API_KEY="your-api-key"
docker compose run --rm codex-chat
```

Или создайте локальный `.env` из примера и заполните ключ:

```sh
cp .env.example .env
docker compose run --rm codex-chat
```

Compose автоматически читает `.env`; сам бинарник по-прежнему принимает только
переменные окружения. Файл `.env` исключён и из Git, и из контекста сборки
Docker.

Сборка без Compose:

```sh
docker build -t codex-chat-cli:local .
docker run --rm -it \
  -e OPENAI_API_KEY \
  -e OPENAI_MODEL="gpt-5.3-codex" \
  codex-chat-cli:local
```

## Команды чата

- `/help` — показать справку;
- `/status` — показать модель, рабочий каталог и число ходов;
- `/new` или `/reset` — начать новый диалог без перезапуска приложения;
- `/clear` — очистить терминал и заново показать стартовую карточку;
- `/exit` или `/quit` — завершить работу.

Для многострочного сообщения поставьте `\` в конце строки. Цвета автоматически
отключаются, когда вывод перенаправлен в файл. Переменная `NO_COLOR` отключает их
и в интерактивном терминале.

## Проверка

```sh
go test ./...
go build -o bin/codex-chat ./cmd/codex-chat
```

Тесты используют локальный тестовый HTTP-сервер и не требуют API-ключа или
доступа к OpenAI API. При сборке Docker-образа тесты запускаются автоматически.
