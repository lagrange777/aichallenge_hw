# Диалоги задания 25

`comparison.json` / `comparison.md`: два сценария по 12 пользовательских запросов с ответами, обычный строгий RAG и режим с памятью. Поиск на каждом ходе; сохранённые ожидания скрыты от генератора и проверки цитат. Оценки выставляются отдельным вызовом той же модели.

`sessions/`: истории тестовых диалогов и память, сохраняемые CLI; каждая сессия изолирована. В них нет данных реального пользовательского чата или ключей API.

## Демонстрация

[demo.mp4](demo.mp4) — 1280×720, около 2 минут 32 секунд, без звука. Запись состоит только из кадров веб-интерфейса (примерно 2 кадра/с); паузы между действиями сокращены. Ответы и оценки реальные, содержимое страницы не подменялось.

Показаны память цели, замена Docker на локальный запуск, восстановление диалога после обновления страницы, ответ с источниками, уточнение поискового запроса, сравнение 10-го и 12-го ходов обоих сценариев и отказ от выдуманного срока. Начальный диалог и его четыре успешных ответа выполнялись в отдельном демонстрационном профиле; полный контрольный прогон показан через сохранённый отчёт во вкладке RAG.

В записи виден временный сбой API и успешное продолжение. Предупреждение в боковой панели про предложения памяти относится к прежнему механизму предложений рабочей/долговременной памяти; отдельный контекст диалога задания 25 успешно сохранён. [demo.png](demo.png) — снимок завершённого отчёта.
