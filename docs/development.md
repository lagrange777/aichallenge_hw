# Запуск и разработка

## Docker

Скопируйте `.env.example` в `.env` и заполните `OPENAI_API_KEY`. Не добавляйте ключ в Git. Compose использует внешнюю сеть `codex-mcp`; при первом запуске создайте её командой `docker network create codex-mcp` (если её ещё нет). Затем выполните `docker compose up -d --build`. Веб-интерфейс доступен на `http://127.0.0.1:8080`. Остановка — `docker compose down`; именованные тома сохраняются.

Основной сервис — `codex-chat`. Отдельные сервисы `demo-order-mcp`, `demo-validation-mcp`, `demo-broker-mcp` обслуживают учебную симуляцию. `project-mcp` получает только `.git` текущего checkout через read-only bind mount. Его порт не опубликован на хост: приложение обращается к нему по внутренней сети Compose. Сам Project MCP не получает API-ключ OpenAI.

README и docs передаются приложению read-only. Изменения в них подхватываются перед следующим /help, без пересоздания контейнера. Корневые исторические инструкции включены в образ и обновляются при пересборке. Индекс хранится в `/data/project-index.json`, в томе `chat-history`. Ключи, `.env`, пользовательская память, логи и артефакты не индексируются. Не размещайте секреты в публичной документации.

Docker-конфигурация рассчитана на обычный checkout с каталогом `.git`. Для linked worktree, где `.git` — файл со ссылкой на другой каталог, нужно отдельно настроить read-only монтирование реальных Git-метаданных. В нативном запуске Git поддерживает worktree штатно.

## Нативный запуск

Нужны Go 1.25+ и Git. Экспортируйте `OPENAI_API_KEY` в оболочку. В первом терминале из корня репозитория запустите `go run ./cmd/project-mcp`, во втором — `go run ./cmd/codex-chat`. Веб-адрес по умолчанию — `127.0.0.1:8080`, MCP — `127.0.0.1:8094`.

`PROJECT_ROOT` задаёт корень документации и Git для соответствующего процесса. `PROJECT_INDEX_PATH` задаёт путь JSON-индекса (по умолчанию `data/project-index.json`). `PROJECT_MCP_URL` задаёт endpoint MCP (по умолчанию `http://127.0.0.1:8094/mcp`). `OPENAI_MODEL` выбирает модель, `OPENAI_BASE_URL` — базовый адрес API, `OPENAI_TIMEOUT` — тайм-аут вызова.

Если MCP остановлен или разрешение его инструментов отозвано, /help показывает предупреждение. Документация остаётся доступной, но текущая ветка считается неизвестной. Повторный запрос после восстановления соединения снова читает актуальное состояние.

## Проверки

`go test -race ./...` запускает тесты; `go vet ./...` проверяет Go-код. Тесты не требуют настоящего ключа и не делают платных запросов. Для ручной проверки откройте чат и отправьте `/help Как устроен проект?`, затем `/help На какой ветке мы сейчас?`. Под ответом доступны источники, цитаты и операции MCP.

Контрольные вопросы и ожидания хранятся в `docs/help-questions.json`; JSON с эталонами не входит в RAG-индекс. `python3 scripts/evaluate-help.py` проверяет запущенное приложение на этих вопросах и сохраняет реальные ответы. Прогон использует облачную модель и оплачивается согласно настройкам OpenAI. Автоматические проверки источников и ключевых фактов дополняют чтение ответов человеком.
