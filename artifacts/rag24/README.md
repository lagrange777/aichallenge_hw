# Демонстрация задания 24

- `comparison.json` — полный прогон 10 вопросов, исходные чанки, два ответа на каждый вопрос, цитаты и оценки.
- `comparison.md` — сравнение в читаемом виде.
- `demo.mp4` — демонстрация работающего приложения после пересборки Docker, около 2 минут, 1280×720, без звука. В кадре только веб-интерфейс.
- `demo.png` — свежий ответ с точной цитатой и результатом проверки.

Сценарий видео: итоговая таблица → ожидания, ответ о TTL и точная цитата → результат смысловой проверки → корректный отказ по неизвестному SLA → новый платный запрос о лимите JSON во вкладке RAG → новый запрос о TTL в обычном чате с включённой проверкой цитат → итоговый отчёт.

Запись сделана последовательностью кадров области веб-страницы (около 2 кадров/с), закодированной в H.264/MP4. Кадры сняты с реального интерфейса; ответы не подменялись. Паузы между отдельными действиями записи сокращены. Рабочий стол, терминал и интерфейс Codex в запись не включены. Сохранённый эксперимент отделён от двух новых запросов демонстрации.
